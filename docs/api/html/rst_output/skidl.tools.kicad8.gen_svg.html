skidl.tools.kicad8.gen_svg module¶

Generate a static SVG drawing of a KiCad 8 schematic.

Like gen_sch, the work is done by the separate schematizer package: this module builds the generic, tool-neutral netlist and asks schematizer to render it as SVG instead of .kicad_sch. Both formats come off the same placement and routing pass, so the drawing matches the editable schematic.

skidl.tools.kicad8.gen_svg.gen_svg(circuit, **kwargs)[source]¶

Generate SVG schematic pages for a circuit.

Parameters:

  • circuit (Circuit) – The circuit to draw. Its nets should already be merged, as Circuit.generate_svg() does before calling.

  • **kwargs – Passed on to schematizer: filepath, top_name, title, and flatness (0.0 for a page per subcircuit, 1.0 for a single page).

Returns:

The directory the SVG files were written to.

Return type:

str

Raises:

  • ImportError – The schematizer package isn’t installed.

  • PlacementFailure – The parts of the schematic couldn’t be placed.

  • RoutingFailure – The nets of the schematic couldn’t be routed.
