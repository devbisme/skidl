skidl.tools.kicad6.gen_sch module¶

Generate KiCad 6 schematic.

The graphical work – placement, routing, writing the .kicad_sch files – is done by the separate schematizer package. This module is the KiCad 6 interface to it: it builds the generic, tool-neutral netlist from the circuit, hands it to schematizer with this KiCad version as the target, and translates schematizer’s failures into SKiDL’s own exception types.

skidl.tools.kicad6.gen_sch.gen_sch(circuit, **kwargs)[source]¶

Generate KiCad 6 schematic files for a circuit.

Parameters:

  • circuit (Circuit) – The circuit to draw. Its nets should already be merged, as Circuit.generate_schematic() does before calling.

  • **kwargs – Passed on to schematizer: filepath, top_name, title, plus engine options such as flatness, retries and auto_stub.

Returns:

The directory the schematic files were written to.

Return type:

str

Raises:

  • ImportError – The schematizer package isn’t installed.

  • PlacementFailure – The parts of the schematic couldn’t be placed.

  • RoutingFailure – The nets of the schematic couldn’t be routed.
